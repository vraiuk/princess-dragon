# Принцесса и Дракон

Пиксельный мультфильм (~2 минуты) в духе пиксель-арта Марка Феррари. Всё рисуется кодом в реальном времени:

- экран 320×180 в индексных цветах (256 цветов) с апскейлом ×4;
- color cycling: вода, водопад, лава, огонь, звёзды и северное сияние анимируются сдвигом палитры;
- дизеринг Байера, слои с параллаксом, процедурные персонажи с обводкой;
- музыка и звуковые эффекты синтезируются через Web Audio;
- озвучка — нейросетевой TTS (edge-tts), губы персонажей синхронизируются с громкостью реплик;
- кнопка «Скачать видео» записывает мультик в mp4/webm.

Смотреть: https://vraiuk.github.io/princess-dragon/
