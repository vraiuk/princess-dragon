# 🐸 Жабка — питомец-программист для macOS

Жаба в наушниках и худи сидит за ноутбуком в углу экрана поверх всех окон и следит, чтобы ты не превратился в сухарь и памятник:

- 💧 **Сохнет без воды.** Стакан рядом с ней пустеет за 45 минут. Потом жаба просит пить, желтеет, покрывается морщинами и трещинами, высовывает язык, над ней поднимается жар.
- 🗿 **Каменеет без движения.** Через 50 минут непрерывного сидения камень ползёт снизу вверх: трещины, мох, застывшие глаза.
- 🚶 **Сама замечает перерывы.** Если 5 минут не трогать мышь и клавиатуру (или заблокировать экран), перерыв засчитывается сам: жаба засыпает, а когда вернёшься — подпрыгнет и стряхнёт камень.
- ⌨️ **Кодит вместе с тобой.** Пока ты печатаешь, она стучит лапками по клавиатуре, вокруг вылетают `{ }`, `</>`, `=>`, глаза следят за курсором по всему экрану.
- 🔔 **Напоминает** облачком с упражнением («10 приседаний — баги сами испугаются»), звуком «ква» и, если игнорировать, системным уведомлением. Повтор через 10 минут, кнопка «Позже».
- 📊 **Считает:** стаканы, перерывы, время за компьютером, самый долгий заход без перерыва.

Всё нарисовано и анимировано кодом на canvas, никаких картинок.

## Как пользоваться

| Действие | Что делает |
|---|---|
| Наведи на жабу | Сбоку появятся кнопки 💧 «попил» и 🤸 «размялся» с кольцами прогресса |
| Клик по жабе | Ква! Шутка или статистика за день |
| Тащи жабу | Переедет куда угодно, место запоминается |
| 🐸 в меню-баре | Статус, «Я попил / размялся», пауза для созвонов, настройки, выход |

В меню-баре рядом с жабкой загораются 💧 и 🗿, когда пора. Прозрачные места окна пропускают клики насквозь, так что работать под жабой можно.

**Настройки** (меню-бар → Настройки): интервал воды (30–90 мин), интервал разминки (30–90 мин), через сколько минут без мыши засчитывать перерыв, частота повторов, размер жабы, звук, системные уведомления, автозапуск при входе.

### Почему такие тайминги

- **Вода — 45 минут.** Около 6 стаканов за 8-часовой день плюс утренний (жаба напомнит при первом включении компьютера утром).
- **Движение — 50 минут.** Классика «50/10»: долгое непрерывное сидение вредно, а короткие перерывы каждый час его компенсируют.
- **Перерыв — 5 минут без мыши.** Отошёл на кухню — засчитано, специально нажимать ничего не нужно. Простой меньше 5 минут (читаешь код, думаешь) перерывом не считается.
- Сон компьютера (закрытая крышка) дольше 5 минут тоже считается перерывом. После сна дольше 2 часов жаба сразу попросит стакан воды.

## Установка

1. Скачай `Zhabka-…-universal.dmg` из [Releases](https://github.com/vraiuk/princess-dragon/releases) (или из артефактов последнего запуска workflow «Жабка — сборка для macOS» во вкладке Actions).
2. Открой dmg и перетащи **Zhabka** в «Программы».
3. Приложение не подписано сертификатом Apple, поэтому при первом запуске: **правый клик → Открыть → Открыть**. Если macOS пишет «повреждено», выполни в Терминале:
   ```sh
   xattr -cr /Applications/Zhabka.app
   ```
4. Жаба появится в правом нижнем углу, 🐸 — в меню-баре. Автозапуск при входе включён по умолчанию.

Сборка Universal: работает и на Apple Silicon, и на Intel.

## Демо в браузере

`app/renderer/index.html`, открытый в обычном браузере, работает как демо: фейковый рабочий стол, перемотка времени ×60/×300 и кнопка «Отойти от компьютера». После публикации на GitHub Pages: https://vraiuk.github.io/princess-dragon/frog-pet/app/renderer/

Для скриншотов состояние можно зафиксировать параметрами: `?dry=0.8&stone=0.5&glass=0&activity=away`.

## Разработка

```sh
cd frog-pet
npm install
npm start          # запустить
npm test           # тесты логики таймеров
npm run dist       # собрать .dmg/.zip (только на macOS)
```

Сборка .dmg идёт в GitHub Actions на macOS-раннере (`.github/workflows/frog-pet.yml`) при каждом изменении `frog-pet/`. Тег `frog-v*` дополнительно публикует релиз.

```
app/
  core.js          логика: таймеры, напоминания, перерывы, статистика (без зависимостей, покрыта тестами)
  main.js          Electron: прозрачное окно поверх всех, меню-бар, простой системы, уведомления, хранение
  preload.js       мост main ⇄ рендер
  renderer/
    pet.js         рисование и анимация жабы на canvas
    demo.js        имитация main для запуска в браузере
build/icon.png     иконка приложения (нарисована тем же кодом)
```

Данные хранятся в `~/Library/Application Support/Zhabka/frog.json`.
