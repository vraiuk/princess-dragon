# 🎬 Жабка: шортсы и YouTube-демо

Сценарии для TikTok / YouTube Shorts / Reels и для длинного ролика на YouTube. Всё снимается без монтажа персонажа: жабу ведёт встроенный **режим съёмки**.

## Как включить режим съёмки

**В приложении:** 🐸 в меню-баре → **🎬 Режим съёмки** → сценарий:

| Сценарий | Длина | Что происходит |
|---|---|---|
| `short` | ~80 с | кодит → стакан пустеет → игнор → сохнет → при смерти → рассыпается пылью → ачивка «Изюм» → надгробие → яйцо → новая жаба → сидит → каменеет → «Железножопая жаба» → рассыпается на камушки → «Нефритовая жаба» → надгробие → возрождение → попила → CTA |
| `water` | ~40 с | только засыхание в изюм, смерть от жажды, надгробие, новая жаба и CTA |
| `stone` | ~42 с | только окаменение, смерть от сидения, надгробие, новая жаба и CTA |
| `tour` | ~116 с | все фичи подряд для длинного демо |

**Куда что:** для TikTok и Reels (лимит 45–60 с) бери `water` (40 с) или `stone` (42 с) — они целиком, со своим хуком и CTA. `short` (80 с) — для YouTube Shorts (до 3 мин). `tour` — для YouTube.

Режиссёр держит правила, их проверяет `test/showcase.test.js`: надгробие с облачком «🥚 Новая жаба» в кадре не меньше 2,5 с перед каждым возрождением; напоминание и «при смерти» не перебиваются (не меньше 2 с на 10 слов); пока жаба в яйце и здоровается, ничего не происходит; в кадре только «сюжетные» ачивки; реплики жабы фиксированы, поэтому каждый дубль звучит одинаково и субтитры можно писать заранее.

Титры (хук, подписи, CTA) показываются и в приложении, и в браузере. Каждый титр — не длиннее 40 символов (до 2 строк даже в окне жабы), в кадре нет пауз без титров дольше 16 с, а числа в титрах не спорят со счётчиками «💧 без воды / 🪑 сидит» над жабой. Во время съёмки время симулированное, твоя настоящая жаба и статистика не трогаются, системные уведомления молчат. Остановить: то же меню → ⏹ Остановить.

**В браузере** (удобнее всего для вертикального видео — жаба крупно по центру, без карточки демо):

```
app/renderer/index.html?film=short&ratio=9:16
app/renderer/index.html?film=water&ratio=9:16
app/renderer/index.html?film=stone&ratio=9:16
app/renderer/index.html?film=tour&stage=desktop   # горизонтально, для YouTube
app/renderer/index.html?film=short&stage=desktop  # запись экрана 16:10 / 16:9
app/renderer/index.html?clean=1                   # без интерфейса демо
```

`stage=desktop` — режим записи горизонтального экрана (1280×800, 1920×1080): без карточки демо, жаба крупно справа внизу, титр и счётчики над ней. Всё важное лежит в правой колонке шириной 9:16 от высоты экрана (на 1280×800 это x 830–1280), её можно вырезать под вертикальный ролик. Без `stage=desktop` в горизонтальном окне остаётся карточка демо с кнопками — это для посетителей, не для записи.

Онлайн: `https://vraiuk.github.io/princess-dragon/frog-pet/app/renderer/index.html?film=short&ratio=9:16`.
Статичные кадры для превью: `?clean=1&dry=0.9&glass=0` (почти изюм), `?clean=1&stone=0.8` (почти камень), `&activity=away` (спит).

## Пять шортсов

Общие правила: хук в первые 2 секунды (текст на экране + действие), крупный текст в верхней трети (не под интерфейсом платформы снизу), субтитры к озвучке, длина 20–45 с (TikTok и Reels — до 45–60 с), последний кадр зацикливается с первым.

**Для TikTok и Reels рекомендуем `water` (шортс 2) и `stone` (шортс 3)**: 40 и 42 с, укладываются в лимит 45–60 с целиком, с хуком, смертью, надгробием, новой жабой и CTA. Шортс 1 (`short`, 80 с) — для YouTube Shorts.

**Для TikTok и Reels** не режь `short`, а снимай `water` или `stone` (шортсы 2 и 3): они целиком укладываются в 45–60 с. Если всё же нужен `short` короче, честно: две смерти с надгробием и вылуплением в 45 с не помещаются, одна смерть с надгробием и яйцом занимает ~23 с. Варианты:
- **Взять 0–37 с** (вода: хук → игнор → изюм → надгробие → Жабка #2) и подложить CTA монтажом. Теряется: окаменение, тосты «Нефритовая» и «Железножопая», финальный глоток и CTA из сценария.
- **Склейка 0–22,5 + 49–62 + 72,5–80 с** (~43 с). Теряется: надгробие «Жабка #1» и первое вылупление, напоминание о разминке, надгробие «Жабка #2» — зритель не видит, откуда взялась новая жаба.
- Ускорять видео не стоит: на ×1,5 облачка уже не успевают прочитать.

**Музыка:** лёгкий lo-fi в начале, на смерти обрыв в тишину + один печальный аккорд, на возрождении снова бит.
**CTA:** «Ссылка в профиле» + закреплённый комментарий с лендингом.

### 2. «Почему моя жаба в изюме» (засыхание, 40 с, для TikTok и Reels)

**Источник:** `?film=water&ratio=9:16`. Таймкоды сценария:

- **0–4,7:** титр **«Что будет, если не пить воду»**, облачко «git commit -m "попью потом"», стакан пустеет.
- **4,7–13,9:** напоминание «Стакан пуст. Попей водички…», «Позже. Ещё один тикет.», титр «не пью воду. Вообще» (7,8 с), кожа желтеет.
- **13,9–18,4:** при смерти, титр «Жаба при смерти» (15,7 с), счётчик «💧 без воды» сверху красный.
- **18,4–22,6:** изюм рассыпается песком, тост «🍇 Изюм».
- **22,6–28,4:** надгробие, титр **«Она просила пить каждые 45 минут»**, облачко «Жабка #1 засохла в изюм. 404: water not found 🪦» с ~25,5 с.
- **28,4–40:** яйцо → новая жаба (~35 с), титр **«Жабка для macOS. Попей воды»** (35,2 с), на 37,4 с жаба пьёт.
- Монтажный хук (по желанию): поставить в начало 1–2 с почти-изюма (кадр ~16 с) с текстом **«Почему моя жаба выглядит так?»** и склейку «2 часа назад».
- **Озвучка:** без голоса, только текст и трек; на смерти — звук ветра.
- **CTA:** «А ты сегодня пил воду? 💧» — провокация в комментарии.

### 3. «Нефритовая жаба» (окаменение, 42 с, для TikTok и Reels)

**Источник:** `?film=stone&ratio=9:16`. Таймкоды сценария:

- **0–4,7:** титр **«Что будет, если не вставать 2 часа»**, облачко «Ещё один фикс — и встану. Честно.»
- **4,7–14:** напоминание о разминке, «Встану после код-ревью», титр «не встаю. Совсем» (7,9 с), камень ползёт снизу вверх. Счётчик «🪑 сидит…» сверху кадра.
- **14–18,9:** при смерти, титр «Жаба при смерти» (14,6 с), на 17,7 с тост «🪑 Железножопая жаба».
- **18,9–26,2:** трещины, камушки, пыль; тост «🗿 Нефритовая жаба».
- **26,2–30:** надгробие, облачко «FATAL: frog #1 hardened. Ты слишком долго сидишь 🪦» с кнопкой «🥚» (после тостов), титр **«Встань раз в 50 минут — жаба заметит»** (27 с).
- **30–42:** яйцо → новая жаба (~36,8 с), титр **«Жабка для macOS. Встань и разомнись»** (36,7 с), на 38,9 с жаба разминается.
- **Озвучка:** «Каждые 50 минут — встань хотя бы на 5. Я не вставал. Вот результат.»
- **Музыка:** эпичный «каменный» бас, на рассыпании — тишина.

### 4. «Ачивки, которыми нельзя хвастаться» (25 с)

**Источник:** `?film=tour&ratio=9:16` или окно 🏆 Трофеи (запись экрана), плюс тосты из `short`.

- **0–2:** тост «🪑 Железножопая жаба» на весь экран. Текст: **«Моё приложение даёт ачивки за плохие привычки»**.
- **2–18:** быстрый монтаж тостов по 2 с, голосом зачитывать описание:
  «🍇 Изюм — можно класть в булочку», «🌙 Ночная жаба — баги любят темноту», «⏰ Snooze-инженер — „потом“ твой любимый спринт», «🐣 Феникс — have you tried turning it off and on again?», «🚰 Гидратированный разработчик — почки сделали апрув».
- **18–22:** окно трофеев: сетка ачивок, вкладка «Кладбище» с эпитафиями.
- **22–25:** **«40 ачивок. Сколько соберёшь ты?»**
- **Музыка:** ретро-чиптюн, звук тоста на каждой ачивке.

### 5. «Отошёл на кухню — жаба знает» (20 с, реальная съёмка)

**Источник:** реальная запись экрана + камера на телефоне (или только экран и `?film=tour`).

- **0–2:** человек встаёт из-за стола. Текст: **«Моя жаба знает, когда я встаю»**.
- **2–8:** экран: жаба наполовину каменная, засыпает (`activity=away`), над ней Zzz.
- **8–14:** человек возвращается, двигает мышь — жаба подпрыгивает и стряхивает камень.
- **14–20:** **«5 минут без мыши = перерыв. Ничего нажимать не надо.»** + «Жабка, macOS, бесплатно».
- **Озвучка:** «Никаких кнопок: отошёл на пять минут — перерыв засчитан, камень слетает.»

### Идеи превью

1. **Сплит «до / после»:** слева зелёная жаба в наушниках, справа изюм. Надпись «2 ЧАСА БЕЗ ВОДЫ». Кадр: `?clean=1` и `?clean=1&dry=0.9&glass=0`.
2. **Каменная жаба крупно** с трещинами, красная стрелка на неё, текст «Я СИДЕЛ 2 ЧАСА». Кадр: `?clean=1&stone=0.8`.
3. **Надгробие «RIP Жабка #7»** и лицо автора с рукой у лица. Текст «Я убил 7 жаб».
4. **Тост ачивки «Железножопая жаба»** на весь кадр, золото + фиолетовый.

Правила: максимум 3–4 слова, контрастная обводка, жаба занимает треть кадра, не прятать важное в правый нижний угол (там длительность видео).

## Чек-лист записи на Mac

**Подготовка экрана**
- [ ] Спрятать иконки рабочего стола: `defaults write com.apple.finder CreateDesktop false && killall Finder` (вернуть: `true`). Или Stage Manager / отдельный пустой рабочий стол.
- [ ] Включить «Не беспокоить» (Пункт управления → Фокусирование), чтобы не вылезли чужие уведомления.
- [ ] Скрыть лишние значки в меню-баре (⌘ + перетащить), часы оставить или скрыть, если ролик «вне времени».
- [ ] Спокойные обои или IDE с красивым кодом без секретов (проверить `.env`, токены, имена клиентов).
- [ ] Курсор: Системные настройки → Универсальный доступ → Дисплей → увеличить размер указателя.
- [ ] Размер жабы в Настройках ×1.5–×2, если снимаешь весь экран.

**Вертикаль 1080×1920**
- [ ] Проще всего: браузер с `?film=short&ratio=9:16`, окно ~540×960 (Retina даст 1080×1920), полноэкранный режим без панелей (`⌘⌃F`, в Chrome — режим киоска/приложения).
- [ ] Или записать весь экран и обрезать до 9:16 вокруг жабы в монтажке (CapCut / DaVinci / Final Cut).
- [ ] Безопасные зоны: текст не ниже ~70% высоты (снизу интерфейс TikTok/Shorts) и не у правого края (кнопки лайков).

**QuickTime**
- [ ] `⌘⇧5` → «Записать выбранную часть», выделить окно с жабой; Параметры → микрофон «Нет» (звук отдельно).
- [ ] Системный звук QuickTime не пишет — «ква» и тосты записывать через OBS или BlackHole.

**OBS (рекомендуется)**
- [ ] Настройки → Видео: базовое и выходное разрешение 1080×1920 (вертикаль) или 1920×1080, 60 fps.
- [ ] Источник «Захват окна» (браузер) или «Захват экрана» + кадрирование (Alt-перетаскивание краёв).
- [ ] Звук приложения: источник «Захват звука приложения» (macOS 13+).
- [ ] Вывод: MP4/MKV, битрейт 12–20 Мбит/с, кодировщик Apple VT H.264/HEVC.

**Перед записью**
- [ ] Прогнать сценарий один раз вхолостую, затем «⏹ Остановить» и запустить заново (режим съёмки каждый раз начинает с новой жабы).
- [ ] Записывать с 2–3 секундами запаса до и после.
- [ ] Звук жабы: Настройки → «Звук» включён; громкость Mac ~50%, чтобы не клиппило.
- [ ] После съёмки вернуть иконки рабочего стола и выключить «Не беспокоить».
